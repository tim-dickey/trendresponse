# Security Policy

## Supported Versions

We provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| 0.x     | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in TrendResponse, please report it responsibly. Do not open a public GitHub issue for security vulnerabilities.

### Reporting Options

1. **GitHub Security Advisory**: Use GitHub's private vulnerability disclosure feature:
   - Go to the repository's Security tab
   - Click "Report a vulnerability"
   - Provide detailed information about the vulnerability

2. **Direct Contact**: For sensitive security issues, you can contact the maintainer directly through GitHub's security advisory system.

### What to Include

When reporting a vulnerability, please provide:

- Description of the vulnerability
- Steps to reproduce (if applicable)
- Potential impact
- Suggested fix (if you have one)
- Your contact information

### Response Timeline

- **Initial Response**: We will acknowledge your report within 48 hours
- **Investigation**: We will investigate and determine the severity
- **Fix Development**: We will work on a fix as quickly as possible
- **Release**: A patched version will be released
- **Disclosure**: Once a patch is released, we will acknowledge the reporter (unless they prefer anonymity)

## Security Best Practices

When using TrendResponse:

- Keep your version up to date
- Review security advisories regularly
- Report any security concerns responsibly
- Do not commit sensitive credentials in your code

Thank you for helping keep TrendResponse secure!
